# Multi-Class-AI-Text-Attribution-with-Explainable-Localization-via-Fine-Tuned-Pre-trained-Model
Neoscholar 2026 Summer Research

This project intends to build a fine-tuned pre-trained model that can detect whether a text is human-written or AI-generated, and classify which of the state-of-the-art LLMs this text might be generated with, through percentage bar of probabilities of each class.
Simultaneously, the model gives a comprehensive locating reference to highlight which segment of the text could be human-written or AI-generated, and also a reasoning module that tells users why they are.
The pre-trained model is DeBERTa-V3-Base, and the link is https://github.com/microsoft/DeBERTa in GitHub.
The model has been on a lot of experiments, proven to be mostly accurate in predictions of random texts.
